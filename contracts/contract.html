甲乙雙方權利義務契約

立契約書人：

甲方：＿＿＿＿＿＿

乙方：＿＿＿＿＿＿

第一條　契約目的與基本原則

甲、乙雙方基於自願及平等原則訂立本契約， 約定雙方之權利、義務、要求權及拒絕權。

本契約之目的，在於明確規範雙方可以要求及拒絕之事項， 並建立合理之違約處理及權利保障機制。

第二條　每日要求限制

甲方每日最多得向乙方提出 3 次要求。

超過 3 次之要求，不屬於本契約約定之要求， 乙方無義務接受。

第三條　乙方拒絕權

乙方每日享有 2 次無須說明理由之拒絕權。

乙方行使拒絕權後，該次要求即視為拒絕。

未使用之拒絕次數不得累積至翌日。

第四條　要求之限制

甲方提出之要求必須：

  1. 屬於雙方約定之契約範圍。
  2. 不違反法律。
  3. 不違反公序良俗。
  4. 不侵害乙方依法享有之權利。
  5. 不要求乙方從事明顯危險或不合理之行為。

不符合上述條件之要求，乙方得拒絕， 且不計入每日 2 次拒絕權。

第五條　乙方之言論與名譽保護權

甲方不得故意散布關於乙方之 不實言論， 或以明知不實之方式向第三人傳述、發布或轉載關於乙方之資訊。

如甲方已散布不實資訊，且乙方合理要求甲方協助澄清， 甲方應於合理範圍內協助澄清，包括：

  1. 向原先接收該資訊之對象說明原資訊不正確。
  2. 在原發布管道或相當之範圍內進行更正。
  3. 不得繼續故意散布相同之不實資訊。

第六條　澄清之限制

乙方要求甲方澄清時， 澄清內容應以更正不實資訊及恢復事實狀態所必要之範圍為限。

乙方不得要求甲方：

  1. 發表虛假聲明。
  2. 承認不存在之事實。
  3. 公開私人資訊。
  4. 從事違法行為。
  5. 對第三人作出與事實不符之陳述。

第七條　違約之定義

甲方違約：

  1. 當日提出超過 3 次契約要求。
  2. 要求乙方履行已被乙方合法拒絕之事項。
  3. 因乙方行使拒絕權而對乙方進行報復或不利處置。
  4. 故意散布關於乙方之不實言論。
  5. 在已知資訊不實後仍故意繼續散布。
  6. 無正當理由拒絕履行本契約約定之澄清義務。

乙方違約：

  1. 接受要求後，無正當理由拒絕履行已承諾之事項。
  2. 故意規避已同意履行之契約義務。

第八條　違約處理

一方發生違約時，他方應先通知違約方， 並給予合理期間改正。

違約方於期限內完成改正者， 原則上不再負擔額外違約責任。

第九條　違約責任限制

違約責任以填補實際損害為原則， 不得藉由本契約對違約方施加不合理或無限制之處罰。

不得因一次違約而：

  1. 永久增加甲方之要求權。
  2. 永久取消乙方之拒絕權。
  3. 要求違約方從事與原契約無關之事項作為處罰。
  4. 剝奪當事人依法享有之權利。

第十條　契約有效期間

本契約有效期間自 ＿＿年＿＿月＿＿日 起至 ＿＿年＿＿月＿＿日 止。

契約期限屆滿時，本契約原則上自動終止， 雙方無須另行通知。

如甲、乙雙方均同意繼續履行本契約， 得於期限屆滿前另行約定續約。

除本契約另有約定或法律另有規定外， 契約終止後，雙方未來之要求權、拒絕權及其他尚未發生之契約義務均停止。

第十一條　契約終止

一方重大違約，經他方通知後仍未於合理期間內改善者， 他方得依契約約定或適用法律主張終止或解除契約。

任一方如欲於有效期間屆滿前提前終止契約， 應於 3 日前通知他方。

契約終止後，雙方未來之要求權與拒絕權即停止。

第十二條　法律限制

本契約任何約定均不得排除適用法律之強制規定， 亦不得違反公序良俗或侵害當事人依法享有之權利。

如部分條款依法無效，其餘條款之效力不受影響； 但依法應全部無效者，不在此限。

第十三條　契約變更

本契約之修改、增加或減少，應經甲、乙雙方同意。

任何一方不得單方面增加對方之義務或減少對方依法或依契約享有之權利。
